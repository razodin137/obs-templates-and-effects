# OBS Templates and Effects

An OBS Studio scene collection with a stack of image sources, groups, and a full effects chain — chroma key, luma key, color key, LUTs, scroll, sharpen, and more.

**Repository:** [razodin137/obs-templates-and-effects](https://github.com/razodin137/obs-templates-and-effects)

## What's here

- [obsOGdisoveryofeeffects](./obsOGdisoveryofeeffects) — an OBS scene collection JSON (import it via OBS: **Scene Collection → Import**).

## What's inside the collection

The scene includes:

- **Sources** — two V4L2 video capture devices (webcams), Xcomposite window capture, seven image sources, and an image slide show.
- **Groups** — five groups organizing the layered image stack.
- **Effects / filters** — Apply LUT, Chroma Key, Color Correction, Color Key (two variants, including a "wavy" one), Image Mask/Blend, Luma Key (two variants), Scaling/Aspect Ratio, Scroll, and Sharpen.
- **Audio** — desktop audio and mic/aux devices, with quick transitions (cut/fade) configured.
